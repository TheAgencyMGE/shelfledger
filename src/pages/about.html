About

ShelfLedger is a release radar for action figures, Funko Pops, anime figures and other collectibles. It tracks new announcements, preorders, exclusives and upcoming drops. There is no account, and nothing you enter leaves your browser.

Coverage

A daily job reads public listing pages, one request per listing, and writes what it finds to a static file. It identifies itself as ShelfLedgerBot, reads robots.txt first, and never requests individual product pages.

Loading coverage.

When a source breaks, its entries are kept from the previous run and the radar says so rather than quietly dropping them. Nothing in the feed is invented: if a manufacturer is not in the first list, ShelfLedger is not tracking it.

Where your data lives

Your collection and wishlist go into IndexedDB, a database built into your browser, on your device. Nothing else. No cookies, no accounts, no server copy. Clearing site data deletes it permanently and nobody can restore it for you, which is the trade for nobody being able to read it.

What this app requests

Three kinds of file, all from this same domain:

  • the pages, styles and scripts;
  • data/releases.json, the release feed;
  • data/catalog/*.json, the shared item catalogue, fetched when you search.

Identical files for everyone. No query strings, no identifiers, no request bodies. No analytics of any kind, no error reporting, no third-party fonts, no embeds, no iframes.

Wishlist matching

The radar flags releases that line up with your wishlist. The feed is public and the same for every visitor; the comparison runs here in the page, against the list stored on this device. No server learns what you are hunting for.

Backups replace sync

Export writes your whole collection to one JSON file, and import reads it back. Getting that file to another device is up to you, which is less convenient and a lot more private than an account.

Scanning

Scanning uses your browser's own barcode decoder where one exists, and a copy of ZXing served from this domain where it does not. Camera frames are read and discarded in the page. No image and no scanned number is uploaded, and the camera stops when you close the scanner.
